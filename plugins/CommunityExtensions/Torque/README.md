# Torque Extension for Numi

## What is this extension for?

This extension allows you to easily convert between common torque units such as Newton-meters, foot-pounds, inch-pounds, and more.

## How to use it

```
100 Nm in ftlb
50 ftlb in Nm
200 inlb in Nm
15 ozin in Nm
10 kgfm in Nm
500 Ncm in Nm
1 Nm in dNm
```

## Supported units

| Unit | Phrases |
|------|---------|
| Newton-meter | Nm, newton meter |
| Foot-pound | ftlb, lbft, foot pound |
| Inch-pound | inlb, lbin, inch pound |
| Kilogram-force meter | kgfm |
| Kilogram-force centimeter | kgfcm |
| Newton-centimeter | Ncm |
| Deci-Newton-meter | dNm |
| Millinewton-meter | mNm |
| Kilonewton-meter | kNm |
| Ounce-force inch | ozin |
